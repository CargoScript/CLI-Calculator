#  Python Command- Line Interface Calculator

An interactive Command-Line Interface (CLI) calculator built with Python. 

This project demonstrates the step-by-step evolution from a basic script to an advanced calculator featuring loop controls, error handling, and continuous calculations.

---

##  Features

* **Basic Arithmetic Operations:** Supports addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
* **Advanced Calculation Mode:**
  * Use the previous result directly for follow-up calculations (`w`).
  * Start a fresh calculation at any time (`n`).
  * Safely exit the program (`e`).
* **Error Handling & Robustness:**
  * Prevents crashes from invalid inputs (e.g., entering text instead of numbers) using `try-except` (`ValueError`).
  * Validates operators before executing calculations.

---

##  Concepts Learned (Python)

* **Control Flow:** `if`, `elif`, `else`
* **Loops:** `while True`
* **Exception Handling:** `try`, `except ValueError`
* **String Formatting:** Formatted String Literals (`f-strings`)
* **Input Processing & Type Conversion:** `float()`, `input()`, `.lower()`
